# 每个业务独立配图校验

本轮范围包括 70 个业务详情封面和 12 个分类入口封面。业务列表卡片和它自己的详情使用同一图片；原始参考相册不参与封面唯一性统计。

- Node 测试检查 82 个图片路径互不重复，并逐文件计算 SHA256，拒绝把同一文件改名后重复使用。
- Python 使用 Pillow 完整解码图片，检查尺寸和 RGB 像素摘要，拒绝只重新编码同一张图片。相近构图会生成候选清单供人工审核，避免将两张相似题材照片误判为重复。
- 浏览器在电脑和手机逐条打开 70 个业务，检查图片加载、卡片与对应详情一致、详情图片在正文上方、页面没有横向溢出，并抽取餐饮、网络、缴费详情截图。
- 验证所有 51 个已导入业务仍在，班车、小巴、如约巴士及校园网络服务点的完整表格行保持不变。网站文字和助手回答不得暴露文档名称、原文链接或来源页码。

运行：

```powershell
node --test tests/unique-images.test.mjs
$env:BROWSER_EXECUTABLE = 'C:\Users\35188\AppData\Local\ms-playwright\chromium_headless_shell-1208\chrome-headless-shell-win64\chrome-headless-shell.exe'
python tests/unique-images-browser.py
```

浏览器测试连接 `http://127.0.0.1:8787`，也可使用 `PREVIEW_URL` 指定预览地址。生成的截图及像素核验报告位于 `qa/unique-images/`。

只替换少数图片时，可以指定条目复验，避免重复运行全部页面检查：

```powershell
python tests/unique-images-browser.py --entry pdf-takeout-wuyougo --entry pdf-takeout-kuaituan
```

专项模式仍会完整解码、比较全部 82 张封面并更新总览图；浏览器只检查指定业务的电脑和手机页面。
